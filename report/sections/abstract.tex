\begin{abstract}

This laboratory studies malicious SSH sessions as sequences of Bash entities and their associated MITRE ATT\&CK tactics.
We first characterize the labelled dataset and examine how tactic assignment depends on command context.
We then compare a general-purpose BERT tokenizer with the code-oriented UniXcoder tokenizer, quantify their behavior on shell commands and complete sessions, and apply word truncation to control pathological token growth.
Subsequent stages fine-tune and compare transformer models for tactic prediction and use the best configuration to analyse unlabelled honeypot sessions.

\end{abstract}
